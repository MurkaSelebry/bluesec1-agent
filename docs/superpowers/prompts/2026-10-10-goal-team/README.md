# Промпты для запуска команды BlueSec

Для каждой задачи выбери проект `bluesec1-agent` и модель `gpt-6-astra`, reasoning `xhigh`. Промпт задаёт работу, настройка модели выбирается в интерфейсе Codex.

1. Сначала запусти [C — координатор](C-coordinator.md) в Local, в `/Users/selebry/Documents/dev/pt/bluesec1-agent`.
2. Дождись сообщения `BASE_READY` с названием ветки и SHA подготовленной версии. Она должна включать текущие незакоммиченные доработки, контракты и эти документы.
3. Создай отдельные задачи в Worktree от указанной координатором ветки: [A — расследование](A-investigation.md), [H — harness](H-harness.md), [R — ревьювер](R-reviewer.md). Скопируй в каждую весь соответствующий промпт. Получится четыре активные роли вместе с C.
4. Когда C выдаст `E_READY` и освободится слот, создай [E — эксперименты](E-experiments.md) в Worktree от интеграционной ветки, указанной C. E сначала готовит проверки и manifest. Реальные вызовы начнутся после технической проверки конкретной версии и manifest координатором и ревьювером.

Каждый промпт включает собственный goal и ссылается на [общие правила](common.md), [план](../../plans/2026-10-10-goal-team.md) и [спецификацию](../../specs/2026-10-10-goal-team.md). Их можно прочитать по абсолютным путям даже из новой рабочей копии. Если задача была открыта раньше нужного checkpoint, её агент проверит расхождение и подготовит безопасную рабочую копию без удаления твоих изменений.

Задачи создаёт пользователь. Координатор связывает уже созданные задачи и объединяет результаты. Короткие сообщения между этими задачами разрешены; работа также должна продолжаться через общие файлы, если инструменты сообщений недоступны.

Общее место передачи результатов — `reports/goals/` в основном репозитории. Каждый агент пишет только свой отчёт; C ведёт `coordination.md`. Это отдельные файлы, а не предположение об автоматической синхронизации разных worktree. Пока исполнители не запущены, этих отчётов может не быть.

Вставка промптов в задачи означает запуск реализации в рамках утверждённого плана. Подготовка этих файлов сама по себе goals и BlueSec-прогоны не запускает.
